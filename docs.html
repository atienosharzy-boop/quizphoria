📖 Developer Setup & Architecture

Learn how Quizphoria is structured using Go and JSON data files.

1. Running the Go Backend

To run the native Quizphoria engine on your terminal, ensure Go is installed and execute:

go run main.go

2. JSON Data Structure

Questions are dynamically populated using standard JSON format inside questions.json:

[
  {
    "question": "What is the primary keyword used to declare a package in Go?",
    "options": ["module", "package", "import", "main"],
    "answer": 1
  }
]
