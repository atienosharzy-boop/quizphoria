📖 Developer Setup & Architecture

Explore the architecture, security guarantees, and API specifications for Quizphoria.

1. Running the Go Backend

The backend is a zero-external-dependency HTTP service built with Go standard library:

go run main.go
# Server listens on http://localhost:8080 (or $PORT)

2. API Contracts & Security Guarantees

Data Protection: The public /api/questions endpoint strips answer keys and explanations to enforce server-side integrity.

Public Question Contract: 

[
  {
    "id": 1,
    "category": "Science",
    "question": "Which planet in our solar system has the most confirmed moons?",
    "options": ["Saturn", "Jupiter", "Uranus", "Neptune"],
    "hint": "It is famous for its bright, prominent ring system."
  }
]
